# Скилл Claude Code: комментарии в соцсетях

Пример настоящего рабочего скилла для [Claude Code](https://claude.com/claude-code).
Скилл продвигает мобильное приложение [VibeLing](https://vibeling.app) (учить
иностранные слова) комментариями на трёх площадках: Reddit, Threads и Дзен.

Это не шаблон «для галочки», а тот самый скилл, которым сессии идут каждый день,
со всеми правилами, выросшими из ошибок: баны в сабреддитах, комментарии, которые
опознали как ИИ, минусы за шилл. Продуктовые факты (цены, лимиты, языки) оставлены
как есть, чтобы было видно, как скилл их использует.

## Как устроено

```
.claude/skills/social-comments/
├── SKILL.md           # точка входа: ротация площадок, раскрытие авторства, анти-ИИ правила
├── reddit.md          # Reddit: выбор треда, правила сабов, отправка через old.reddit
├── threads.md         # Threads: поиск, голос фаундера, отправка
├── dzen.md            # Дзен: комментарии под чужими статьями
├── subreddits.md      # карта сабреддитов: где упоминать продукт можно, где нет
├── product-facts.md   # что про продукт можно говорить, а что нельзя
└── voice.md           # как пишет автор: примеры «хорошо / плохо»

scripts/
├── reddit/  threads/  dzen/   # чтение страниц через залогиненный Chrome
└── chatgpt-app/uictl.swift     # клики и ввод в окно Chrome (macOS Accessibility + CGEvent)

content/*-log.json             # журналы: что написано, где, как оценили
```

Главные идеи, которые стоит забрать себе:

- **Скилл разбит на файлы.** `SKILL.md` короткий по смыслу и ссылается на детали;
  Claude подгружает `reddit.md` или `dzen.md`, только когда работает на этой площадке.
- **Правила с датой и причиной.** Каждое «нельзя» объяснено реальным случаем:
  так модель понимает, *почему*, и не нарушает правило в пограничной ситуации.
- **Факты о продукте отделены от голоса.** `product-facts.md` отвечает на «что можно
  утверждать», `voice.md` на «как это сказать». Выдумывать цифры запрещено явно.
- **Журналы.** По ним считаются лимиты и доля упоминаний продукта, поэтому сессия
  может идти часами и не скатиться в спам.

## Запуск

Нужны macOS, Chrome с залогиненными аккаунтами и Node.js. Собрать `uictl`:

```bash
swiftc -O scripts/chatgpt-app/uictl.swift -o scripts/chatgpt-app/uictl
```

Терминалу нужно разрешение Accessibility (Системные настройки → Конфиденциальность).
Дальше в Claude Code: «поработай в соцсетях».

Чтобы адаптировать под свой продукт, перепишите `product-facts.md`, `voice.md` и
легенду в `SKILL.md`, ники аккаунтов и карту сабреддитов.
